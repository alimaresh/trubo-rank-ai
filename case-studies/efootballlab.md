# eFootballLab AI Referral and Search Opportunity Case Study

This study shows how an established content website can use real AI referral data and search context to decide which pages deserve improvement first.

**Official live study:** [eFootballLab Search Opportunity Case Study](https://truborankai.com/case-study-efootballlab-search-opportunities)

**Evidence snapshot:** August 6, 2026

## Measured AI Referral Results

The owner-supplied aggregate referral export recorded:

- **791 visits** from AI answer platforms
- **1,083 AI-referred pageviews**
- **758 ChatGPT visits** and **1,039 ChatGPT pageviews**
- ChatGPT ranked **sixth** among 122 recorded referral sources
- Measured referrals from ChatGPT, Claude, Perplexity, and Gemini

ChatGPT represented 95.8% of the measured AI-platform visits in this snapshot. This is directly observed referral traffic, not estimated AI visibility.

## Why the Analysis Matters

When a website already contains many pages, publishing more content is not automatically the best next action. Search impressions, clicks, average position, referral traffic, page intent, crawlability, internal links, and content clarity can reveal where existing demand is not being served well.

The eFootballLab workflow uses that context to identify:

- existing pages worth improving;
- content gaps where search intent is not answered clearly;
- technical issues that should be fixed before adding content;
- opportunities for stronger internal linking;
- pages that can be made clearer for search engines and answer engines.

## SEO, AEO, and GEO Workflow

1. Review existing search signals and referral sources.
2. Find pages with measurable demand but weak performance.
3. Compare the page promise with the likely user question.
4. Check technical access, canonicals, structure, and internal links.
5. Prioritize the smallest useful set of changes.
6. Monitor search and AI referral evidence after the improvement.

This workflow supports traditional SEO, Answer Engine Optimization (AEO), and Generative Engine Optimization (GEO), but it does not claim that any single change guarantees a ranking or AI citation.

## Methodology and Limitations

The figures are cumulative values from an aggregate referral export captured on August 6, 2026. Source-level visitor counts are not summed as deduplicated site users. A reliable before-and-after claim requires a matching comparison period, so this study reports the observed acquisition channel and the decision workflow without inventing uplift.
